# Documentación Técnica — Kitchos

Bienvenido a la documentación interna del proyecto **Kitchos**, una aplicación web para la gestión de recetas y planificación de comidas.

Este espacio documenta el trabajo detrás del proyecto: decisiones técnicas, arquitectura, flujos de trabajo, implementación y estrategia de desarrollo.

---

## Estructura de la documentación

```
docs/
├── index.md                         # Este archivo (índice general)
├── 01-arquitectura/                 # Decisiones y diseño arquitectónico
├── 02-decisiones-tecnicas/          # ADRs y justificaciones técnicas
├── 03-flujo-de-trabajo/             # Procesos de desarrollo, review, release
├── 04-implementacion/               # Detalles de implementación por módulo
└── 05-git/                          # Estrategia de ramas, commits, convenciones
```

## Cómo contribuir a esta documentación

1. Crea o modifica archivos Markdown (`.md`) dentro de la carpeta `docs/`.
2. Sigue el orden numérico de las carpetas para mantener la organización.
3. Usa lenguaje claro y en español.
4. Incluye contexto sobre *por qué* se tomaron ciertas decisiones, no solo *qué* se hizo.
